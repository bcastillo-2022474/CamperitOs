# CamperitOs

Un proyecto comunitario para construir, desde Guatemala, una distribución de Linux basada en Fedora.

> **Estado: idea inicial.** Todavía no hay código funcional, ISO ni instalador. Este repositorio es el punto de partida.

## Qué queremos hacer

Queremos crear una distro opinionada, con un entorno de escritorio ya configurado para trabajar, pensada para nuestro contexto. La inspiración es proyectos como Omarchy, pero partiendo de Fedora.

Es un proyecto de aprendizaje: lo hacemos por Linux, para Linux, y para armar una comunidad en Guatemala alrededor de él.

## Qué todavía no está definido

Casi todo. Lo que sí sabemos:

- La base será **Fedora**.
- El código será open source (ver [Licencia](#licencia)).

Lo demás (herramientas, escritorio, instalador, arquitecturas soportadas, nombre definitivo) se va a decidir en el camino y se documentará aquí conforme exista.

## Cómo participar

Estamos empezando, así que por ahora la mejor forma de ayudar es opinar y proponer:

- Abrí un **issue** con ideas, preguntas o propuestas.
- Si querés contribuir con código o documentación, hacelo con un pull request y firmá tus commits con `Signed-off-by` ([DCO](https://developercertificate.org/)).

Contacto: `https://www.instagram.com/sudoers.os`
