---
title: Cómo participar
description: Formas de colaborar mientras el proyecto está en etapa inicial.
---

Por ahora, la mejor forma de ayudar es opinar y proponer.

- Abrí un **issue** con ideas, preguntas o propuestas.
- Para aportar código o documentación, abrí un **pull request** con tus commits firmados ([DCO](https://developercertificate.org/)).

```bash frame="terminal" title="bash"
# -s agrega la línea Signed-off-by al commit
git commit -s -m "docs: aclara la introducción"
```

:::tip
No hay pregunta incorrecta. Si apenas estás empezando, contanos qué te gustaría aprender.
:::
